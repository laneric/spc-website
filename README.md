# Software Product @ Cal

Marketing site for [Software Product @ Cal (SPC)](https://spcberkeley.org), UC Berkeley’s student chapter of the International Software Product Management Association (ISPMA).

SPC ships live client projects, teaches product management from first principles, and connects students with product leaders through ISPMA.

## Site

Live at [spcberkeley.org](https://spcberkeley.org).

| Route | Contents |
| --- | --- |
| `/` | Home |
| `/about` | Culture, how the club works, leadership |
| `/ispma` | ISPMA partnership, summit, and India conference |
| `/services` | Client offerings and past projects |
| `/community` | Alumni careers |
| `/join-us` | Recruitment |

## Stack

Next.js (App Router), React, TypeScript, and Tailwind CSS. Typography is Inter and Instrument Serif.

## Local setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
